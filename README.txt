RIDE REBORN — quick-start project

1. Extract ride_reborn_project.zip.
2. Open the extracted "ride_reborn" folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server".
   If Live Server is not installed, install the "Live Server" extension in VS Code.
5. Internet is required for the online motorcycle photos and Google Fonts.

Files:
- index.html  : website structure
- style.css   : cinematic design, responsive layout and animations
- script.js   : bike selector, spec updates and mobile menu

This is a front-end concept website. Bike specifications are illustrative demo content;
verify official manufacturer specifications before using them in a formal presentation.
